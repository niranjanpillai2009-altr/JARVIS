This file is the April 2026 version of the JARVIS plugin.
It was made to run in a VSCode environment.
The assets contained within are to run a PyBullet simulator.
If you don't have PyBullet, you'll need to install PyTorch and
some add-ons to make it run on your computer.

This version of JARVIS is tied into it's own PyBullet workflow.

You will need to have an OpenAI API Key, and change the .env
variable to make this run.
